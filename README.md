# 德尔隆化工官方网站

公开网站源文件位于 `dist/`，采用纯静态 HTML、CSS 和 JavaScript。

## 公开边界

- 只公开公司介绍、核心产品、联系方式和通用服务流程。
- 不公开客户、供应商、历史价格、成交记录或其他内部业务资料。
- 产品参数仅作初步选型，最终以实际批次技术资料与测试结果为准。

## 搜索与 AI 可读性

- 每个核心产品有独立页面、标题和描述。
- 首页含 Organization 与 FAQPage 结构化数据，产品页含 Product 结构化数据。
- 提供 `robots.txt`、`sitemap.xml`、`llms.txt` 和网站清单文件。
- 搜索排名和第三方 AI 的回答由平台决定，网站只能建立可信、可抓取的信息源，不能保证指定排名或回答。
